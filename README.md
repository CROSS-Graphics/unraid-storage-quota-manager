# Storage Quota Manager

Fixed-capacity private SMB storage for Unraid, maintained by **CROSS Graphics**.

**Initial public beta.** This candidate uses the maintainer-selected **1.5.0** baseline. The maintainer reports testing on their own server. Automated tests simulate Linux and Samba operations; they do not replace independent Unraid validation. See [testing](docs/TESTING.md) and [known issues](docs/KNOWN-ISSUES.md).

## Features

- Create fully allocated filesystem images on compatible mounted local storage.
- Choose ext4, XFS or Btrfs inside a new image; the physical disk is not formatted.
- Private SMB access using existing Unraid accounts; check users and assign Read or Read/Write.
- Main-tab overview with capacity, used/free space and mount/unmount controls.
- Array lifecycle integration, persistent metadata and conservative creation rollback.
- Increase capacity without formatting. Shrinking is prohibited.
- Separate Remove Share, Detach and permanent Delete operations.

## Requirements and limitations

- Target: Unraid 7.x with its built-in PHP, util-linux, Samba and filesystem utilities. The version range is a target, not a claim of testing on every 7.x release.
- Backing storage: mounted local XFS, ext4 or Btrfs. This baseline also discovers compatible local mounts under `/mnt/disks/`; external hot-plug management has not been independently validated.
- NTFS, exFAT, FAT, network shares, read-only mounts and loop-backed parent volumes are unsupported.
- The image reserves its full length, plus the operation requires 1 GiB of remaining free space. Filesystem metadata reduces usable capacity.
- No guest access, passwords, physical partition formatting, forced unmounts or automatic destructive repair.
- Authorized users share filesystem ownership as `nobody:users`; SMB enforces their individual read/write permissions.
- Backups remain necessary. Growth, power loss, device failures and third-party root plugins can affect data.

## Installation

Install only the project's published `quota-manager.plg` using Unraid **Plugins → Install Plugin**, or download it to the server and run:

```bash
plugin install /path/on/server/quota-manager.plg
```

Open **Settings → User Utilities → Storage Quota Manager**. Create a storage, select its users and access levels, then connect to `\\YOUR-SERVER\StorageName` with an authorized Unraid SMB account.

Existing disks and accounts are not created or reformatted. An ordinary user share is not created: each managed volume is a separate SMB resource. Windows permits multiple connections under one account, but can reject different credentials for the same server while previous sessions exist.

## Updates and removal

Updates temporarily close managed SMB connections and unmount images, then restore the previously mounted set. Close files before updating. If a busy filesystem cannot unmount, installation stops rather than forcing it.

Uninstall through Unraid Plugins. Images and persistent metadata are retained. **Remove Share** disables SMB, **Detach** also unmounts, and the red **Delete** button permanently removes the entire virtual image only after exact confirmation.

## Development

```bash
sudo php tests/run.php
php tests/updates.php
npm ci
npm test
python3 tools/build.py
python3 tools/check_package.py
python3 tools/validate_publication.py
```

The `sudo` test invocation on Linux accommodates the baseline's root-owned-directory checks. All storage/Samba commands in transaction tests are simulated; only temporary test files are used. Never run destructive validation on a production array.
